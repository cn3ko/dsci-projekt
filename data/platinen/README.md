platinen
========

Die Originalfotos der Platinen, je eine Platine pro Foto auf hellem
Hintergrund. Dateien mit bad_ am Anfang zeigen fehlerhafte Platinen,
sample_ic_auf_ruecken_* sind Aufnahmen mit einem IC, der auf dem Rücken
liegt.

Diese Bilder werden nie verändert. Alles Weitere wird aus ihnen erzeugt, so
lässt sich jeder spätere Schritt jederzeit aus den Originalen wiederholen.

Weiter geht es mit:

    python -m pcb_inspection.platinen
