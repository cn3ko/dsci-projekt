beispiele
=========

Einzelne Bilder, um die Vorhersage des fertigen Modells schnell
auszuprobieren:

    python -m pcb_inspection.klassifikator predict data/beispiele/IMG_0100.png

Die Bilder hier gehören weder zu train noch zu val. So zeigt die Vorhersage,
wie sich das Modell auf einem neuen Bild verhält.
